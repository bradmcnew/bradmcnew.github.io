# Brad McNew - Personal Portfolio

Welcome to my personal portfolio website! This repository contains the source code for my portfolio hosted on GitHub Pages at [bradmcnew.github.io](https://bradmcnew.github.io).

## Overview

This site serves as a showcase for my projects, skills, and professional background. It is built using the Jekyll static site generator with a customized theme for a professional and modern appearance.

## Features

- **Projects**: Highlights of my work with descriptions, links, and images.
- **Resume**: Downloadable PDF of my resume with my education and experience details.
- **Blog**: A space for sharing insights, tutorials, and updates.
- **Contact**: A form to reach out to me directly.

## Development

To develop and test this site locally, follow the steps below:

1. Clone this repository:
   ```bash
   git clone https://github.com/bradmcnew/bradmcnew.github.io.git
   ```
2. Navigate to the project directory:
   ```bash
   cd bradmcnew.github.io
   ```
3. Install the required dependencies:
   ```bash
   bundle install
   ```
4. Start the local development server:
   ```bash
   bundle exec jekyll serve
   ```
5. Open your browser to `http://localhost:4000` to view the site.

## Deployment

This site is automatically deployed by pushing to the `main` branch. GitHub Actions handle the build and deploy process.
